# F5-TTS: меньше артефактов без роста шагов + хоть какие-то эмоции (36 поисков, 2026-10-04)

Рамка: `nfe_step` остаётся 10 (память f5-nfe-10). Модель — русский F5TTS_v1_Base. Цель — чище звук и живее интонация без добавления шагов.

## Что нашли
**Шаги уже оптимальны.** EPSS (Fast F5-TTS, arXiv 2505.19931): расписание 10 шагов UTMOS 3.92 против 3.97 у 16 равномерных, 7 шагов — 3.84. Наш F5 уже берёт таблицу EPSS {5,6,7,10,12,16}; sway = −1 лучше 0 (оригинальная статья). Резерва здесь нет.

**Что реально снижает артефакты без шагов**
1. *Best-of-N по ASR* — N кандидатов, берём тот, чей текст ближе к целевому: −10…30% WER у flow-matching TTS (arXiv 2607.08256; оговорка: оценка зависит от семейства ASR). У аудиокниги уже есть проверка GigaAM + один повтор.
2. *Чистый референс*: обрезанное >12 с аудио при неизменной транскрипции даёт повторы, быстрые фразы, неверные паузы (issue #1207); референс ≤15 с с ~1 с тишины в конце; повтор референса ухудшает WER; длиннее референс (5.5→7.7 с) — выше схожесть голоса.
3. *Selective CFG* (arXiv 2509.19668): guidance не на всех шагах — выше SIM при том же WER, без дообучения. Кандидат на потом.
4. *Дробление текста*: предложения со знаками конца, крупные куски, фиксированный seed против «плавающего» тембра между кусками; cross-fade 0.1–0.15 с.
5. Редкий «дропаут» внутри слова (~5% слов) лечится перегенерацией — то же best-of-N.
6. Ничего про fp16/bf16 шум в F5 не найдено; Vocos против BigVGAN — паритет по MOS (BigVGAN чуть лучше WER 2.11 против 2.42).

**Эмоции**
- Родных эмоций в F5 нет (нет тегов, нет «exaggeration»). Эмоция берётся из референса и текста.
- `cfg_strength`: ниже — живее и менее стабильно, выше — стабильнее и «ровнее» (по умолчанию 2). Это единственный ручной регулятор живости без шагов → замер `bench/tts_cfg_ab.py`.
- EmoSteer-TTS (arXiv 2508.03543, неофициальный код sujin-koo/emosteer-tts-unofficial): без обучения, векторы «эмоция − нейтраль» по активациям F5, α≈5–10, top-k≈200; векторы строятся по ESD (английский) — на русском не проверено, работа ~день. Отложено.
- F5-TTS-Emotional-CFG (RaduBolbo): дообучение на ESD, 5 эмоций, английский.
- Кросс-язычный перенос эмоции F5 слаб (arXiv 2509.14579); русский датасет Dusha (350 ч, 4 эмоции) есть, дообучение F5 на нём — отдельный проект.
- Аудиокнигам помогает различие *повествование / прямая речь*: нейтральная подача для рассказчика, живее для реплик (arXiv 2509.04072 и др.).
- ESpeech-TTS-1_RL-V2 (RL-дообученный русский F5, ESpeech/ESpeech-TTS-1_RL-V2, 2.7 ГБ) — кандидат на A/B по артефактам; смена модели меняет тембр, не включена.

## Что сделано в коде
- `ctx.tts_cfg` / `ctx.tts_speed_mul` → `voice_clone.speak(..., cfg=, speed_mul=)` → `infer_process(cfg_strength=…)`; по умолчанию как раньше (2.0 и 1.0).
- `bench/tts_cfg_ab.py`: WER (GigaAM) + разброс F0 + размах громкости по cfg при 10 шагах.

## Замер EmoSteer на нашей модели (bench/emosteer_ab.py, voice/emosteer.py)
Векторы «эмоция − нейтраль» по 22 блокам DiT из ~30 клипов Dusha на эмоцию; оценка — русский SER (hubert-dusha), WER, схожесть голоса. 4 фразы, 10 шагов.
| эмоция | α | P(цель) | WER | SIM |
|---|---|---|---|---|
| angry | 0 → 0.01 → 0.02 | 0.03 → 0.20 → 0.00 | 0.11 → 0.11 → **1.0** | 0.92 → 0.78 → 0.54 |
| positive | 0 → 0.01 → 0.02 | 0.05 → 0.18 → 0.31 | 0.11 → 0.11 → 0.13 | 0.92 → 0.84 → 0.68 |
| sad | 0 → 0.01 | 0.01 → 0.00 | 0.11 → 0.56 | 0.92 → 0.62 |
(α ≥ 0.1 как в статье — речь разваливается, WER 1.0.)

Вывод: окно рабочих α очень узкое (0.005–0.02 от нормы токена); эмоция «злая/радостная» чуть сдвигается, но голос уходит (SIM −0.1…−0.25), «грустная» не получается. Для клонирования голоса это неприемлемо → **не интегрировано**, остаёмся на референсе и пунктуации. Код оставлен как бенч-инструмент.

## Эмоции «как надо»: 50 поисков (2026-10-04), выводы
Требование: радость — высокий тон/выразительная артикуляция; злость — громко, местами высоко; грусть — низко, падение от высокого к низкому; нейтральная — ровная, далёкая, мягкая; вопрос — подъём в конце, смысловое слово сильнее.

**Почему не вышло на F5.** CoCoEmo (arXiv 2602.03420): эмоциональную просодию в гибридных TTS создаёт *языковой модуль*, а не flow-matching часть. F5 — чистый flow-matching без LM, векторы активаций дают узкое окно до распада слов (наш замер). Родной эмоции в F5 нет; ECE-TTS и F5-TTS-Emotional-CFG дообучены на ESD (английский), у русской модели нужен корпус и дообучение (60–300 ч по опыту F5-сообщества). Единственный открытый русский корпус с 12 метками стиля — Dialogs (langswap/dialogs-ru-emotional-conversations, 20.6 ч, 3 диктора, OpenRAIL, коммерция разрешена); мало для надёжного дообучения.

**Рабочий рецепт без дообучения: источник эмоции → конверсия тембра.** OpenVoice: эмоция/ритм/интонация задаются базовым TTS и сохраняются при смене тембра; Seed-VC и Chatterbox-VC (S3Gen) меняют только тембр и держат просодию источника. Схема: Qwen3-TTS (VoiceDesign/CustomVoice + `instruct`, эмоция и просодия) → Seed-VC/Chatterbox-VC в голос пользователя → при необходимости PSOLA-доводка (`voice/prosody.py`) под описанные профили. Ударения: подавать в Qwen текст после `RUAccent`-разметки не получится (не обучена на «+»), поэтому для рассказчика остаётся F5 с акцентором, эмоциональная схема — для реплик и коротких ответов.

**Метрика.** SER Dusha (уже есть) + emotion2vec; измерять P(цель), WER, SIM, F0-профили (медиана, размах, падение к концу фразы, громкость).
