# Аудиокнига в боте: как делают правильно (50 поисков, 2026-10-04) и что сделано

Кнопка «📚 Аудиокнига» (Творчество → Музыка): образец голоса → файл книги → каждая глава приходит голосовым, которое **начинается с названия главы**; под голосовым подпись «📖 Глава 3 · Название · 3/12 · часть 1/2».

## Выводы поисков
1. **F5 держит ~30 с за проход** (референс + результат), поэтому текст идёт кусками из целых предложений, 100–250 символов; фразу не режут посреди оборота (запятая/пробел только для чудовищно длинного предложения).
2. **Дрейф голоса** лечится одним и тем же референсом и транскриптом на каждый кусок (+ фиксированный seed, большие куски). Своё референс-аудио на каждый кусок = дрейф. Сходство куска с референсом можно мерить ECAPA-косинусом (не сделано, см. ниже).
3. **Тишина.** Собственная тишина движка по краям куска разная и читается как заминка: обрезать (−45 дБ, оставить ~60 мс, фейды 8 мс), а паузы вернуть намеренно: ≈300 мс между предложениями, ≈800 мс между абзацами, ≈1,3 с после названия главы (практика: 250–400 / 600–900 / 1500–2000 на границе глав).
4. **Проверка куска.** Пустой/обрезанный/зацикленный кусок ловится дёшево по скорости речи (символов в секунду); один повтор, потом лучший из двух. Полная ASR-проверка и ECAPA — следующий шаг, если плохих кусков будет много.
5. **Главы:** по заголовкам книги («Глава N», «Часть», «Пролог», голые номера/римские цифры отдельной строкой после пустой); короткая «глава» (<600 символов — номер страницы, эпиграф) приклеивается к предыдущей; без заголовков — равные «Часть N» по ~6000 символов по концу абзацев. Названия на следующей строке («Глава 1» / «Начало») склеиваются.
6. **Форматы:** TXT (utf-8/cp1251), FB2 (только основной `<body>`; `notes`/`comments` и картинки не читаются), FB2.ZIP, EPUB/PDF/DOCX через готовые экстракторы проекта (`knowledge.library.extract_text`, только чтение, без индексации). Скан без текстового слоя → честное «не смог прочитать… pdf с текстовым слоем».
7. **Чистка текста:** склейка переносов, сноски `[12]` и надстрочные номера не читаются, «- 12 -» номера страниц убираются.
8. **Telegram:** входящий файл: 20 МБ на облачном Bot API, у нас свой локальный сервер — до 2 ГБ (берём общий `_bot_file_limit()`), голосовое ≤50 МБ; для голосовых > ~5 мин нужно явно передать `duration` (иначе плеер 0:00) — теперь передаётся всегда; глава длиннее 25 мин режется на части по самой тихой секунде у границы; подписи ≤1024 символов.
9. **Русский:** ударения/числа/аббревиатуры делает общий `preprocess_text_for_synthesis` (RUAccent + to_spoken_form), как и для обычной озвучки; отдельной нормализации не изобретаем.
10. **UX длинной работы:** по главам, каждая приходит сразу как готова; ⛔ под заметкой (общий `_run_cancellable`); оценка «≈N мин речи» по длине текста. Возобновление после рестарта не сделано.
11. **Согласие/права:** клонировать можно свой голос или с разрешения владельца; в тексте кнопки просим образец «одного человека» — юридическую плашку не добавляли.
12. **Модель.** Для русского выбор хозяйский — F5-RU (в проекте). Qwen3-TTS/другие не пробовали.

## Изоляция (песочница, RAG, агент)
Пока режим включён, образец и книга **съедаются кнопкой** до всех остальных маршрутов: файл не попадает в библиотеку (RAG), не кладётся в песочницу, текст не уходит к агенту; не-книга отвергается с подсказкой, режим остаётся. Любая другая кнопка меню режим выключает; после завершения книжный файл снова обычный документ. Тест: `tests/test_audiobook_flow.py` (обычный документ вне режима индексируется как раньше; в режиме — нет). Регрессия: sandbox/RAG/library/меню-тесты зелёные.

## Что сделано
- `media/audiobook.py`: чтение книг, главы, куски, обрезка тишины, склейка, нарезка длинных глав, подписи.
- `bot/tg_audiobook.py`: состояния `want_voice → want_book`, задача с ⛔, голосовые с подписями.
- Кнопка в «Творчество → Музыка», строки RU/EN, поля сессии, `_send_voice_from_wav(caption=, duration)`.
- Тесты: `tests/test_audiobook.py` (17), `tests/test_audiobook_flow.py` (18).

## Потолки и дальше
- Нет проверки куска ASR/ECAPA; нет возобновления после рестарта; один голос на всю книгу (диалоги разными голосами — LLM-разметка реплик, не делали); M4B с главами одним файлом — не делали (голосовые по главам).
- Скан PDF без текстового слоя: OCR не подключали.
