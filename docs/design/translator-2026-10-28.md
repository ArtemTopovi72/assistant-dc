# Переводчик

Пользователь поручил самостоятельно выбрать удобные детали. Отдельный переводчик
появляется в Telegram и Workspace: язык назначения, автоматическое определение
исходного языка, текст, надписи на картинке, голосовой перевод своим голосом.

Используем общий небольшой сервис `core/translator.py`, существующий LLM,
OCR и Pillow. Изображение не проходит через генератор: перевод размещается
поверх найденных текстовых областей с подложкой и подбором размера шрифта.
Сохраняются размер и пиксели вне этих областей; оригинал не перезаписывается.
Текст перевода также доступен отдельно. Неизвестные/нечитаемые области не угадываем.

Для речи используем уже установленный изолированный `venv_qwen` и Qwen3-TTS
Base (10 языков), поскольку русский F5 не подходит для иностранной речи.
Отдельный процесс использует существующий GPU scheduler и прекращается по Stop.
Промпт голоса — только присланная запись этой операции, без подмешивания старых
образцов. Все режимы возвращают текст, даже если озвучка недоступна.

Альтернативы: image-edit генератор нарушает явное требование пользователя;
внешний облачный переводчик не нужен при имеющемся локальном LLM. Новую
библиотеку озвучки не ставим: используем установленный Qwen.

Удобства: очистка, копирование и сохранение результата в приложении; постоянные
кнопки режима/языка и выход в Telegram. Выбор языка не меняет язык всего бота.
Ограничения: фотографический фон под буквами закрывается локальной подложкой,
а не восстанавливается; сходство голоса зависит от чистоты образца.

## План выполнения (writing-plans / executing-plans)

- [x] Сервис перевода и наложения, тесты целевого языка, соответствия OCR-блоков,
  сохранности исходника, ограничений и отмены; отдельный Qwen worker.
- [x] Telegram: меню/настройки с сохранением, перехват только входов переводчика,
  обычные кнопки навигации не переводятся; текст/изображение/голос и Stop.
- [x] Workspace: вкладка, язык/режим, текст и выбор файла, результат/копировать/
  сохранить/проиграть/отмена, безопасное завершение worker при закрытии.
- [x] Целевые тесты, независимый review, реальные текст/картинка/голос через
  дебаг-чат, перезапуск приложения и коммит с результатами проверок.

Qwen работает отдельно от обычного русского F5. На этой машине уже установлен
`qwen-tts` в `venv_qwen`; веса [Qwen3-TTS-12Hz-0.6B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)
размещены в `models_ext/qwen3_tts_base` и проверены по SHA256 репозитория.
Если окружения/весов нет, возвращается перевод текстом с понятным объяснением.
Частные исходники, голосовые образцы и результаты не включаются в Git.
