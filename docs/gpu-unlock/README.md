# GPU Unlock: Maxsun Z790 / MSI RTX 3090

[Скачать рецепт и исходники](GPU-Unlock-Maxsun-Z790-SHARE-2026-10-27.zip)

Архив содержит исходный Windows-порт, патч адаптации, тесты, лицензии и инструкцию. Приватных PROM/BIOS-дампов, аппаратных журналов, локального профиля, GUID разделов и готовых EFI в нём нет.

Адаптация испытана на Maxsun MS-iCraft Z790 WIFI с BIOS H7.8G, Intel i7-14700KF и MSI RTX 3090 24 ГБ. Для другого компьютера нужны собственные диагностические снимки, проверка совместимости и профиль. Архив не является универсальным установщиком для RTX 3090.

Разблокировка выполняется в UEFI до загрузки драйвера NVIDIA. Запустить её при старте бота в уже работающей Windows этим способом нельзя. Текущий локальный профиль рассчитан на загрузку с USB; перенос на внутренний диск требует отдельной адаптации и проверки восстановления.

Исходные проекты: [Windows-GPU-UNLOCK](https://github.com/impacifist/Windows-GPU-UNLOCK), [gpu-unlock](https://github.com/Zagitta/gpu-unlock). Контрольные суммы файлов находятся внутри архива в `SHA256SUMS.txt`.
