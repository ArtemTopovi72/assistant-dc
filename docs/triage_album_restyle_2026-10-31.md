# Triage: альбом + «все пять — в стиле киберпанк» = описание вместо рестайла

Обнаружено в ночном QA (2026-10-31 21:03, дебаг-чат 777000001).

## Симптом
Альбом из 5 фото + «все пять — в стиле киберпанк» → модель ОПИСАЛА первую
картинку (дважды, после двух corrective-раундов) — ни один рестайл не выполнен.
Честный guard отработал: «Answer claims an action but no tool was called» ×2,
failed turn сохранён (20261031_210350_19688_guard_corrective.json).

## Корень (два слоя)
1. Текст задачи: «все пять — в стили киберпанк\n[Text written on picture 1
   (OCR...)]» — альбомная OCR-заметка разбавила инструкцию, модель прочитала
   «опиши картинку 1».
2. Стиль-флоу (_push_style_transfer_task) принимает ОДИН target: для альбома
   нет маршрута «рестайль каждого по очереди» — задача уходит в обычный граф
   с одной картинкой и расплывчатым текстом.

## Правильный фикс (feature, не костыль)
В _resolve_and_push: если батч = альбом + текст стиля (киберпанк/акварель/...),
сплитнуть на N задач _push_style_transfer_task (по одной на каждое фото,
задержкой между запусками) с учётом max_queued; или один chain-таск,
итерующий альбом (как long-video части). Плюс: не добавлять OCR-заметку,
когда текст задачи — инструкция стиля (она и есть смысл хода).
