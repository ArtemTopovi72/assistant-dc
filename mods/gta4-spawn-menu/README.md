# GTA IV Spawn Menu

Простое меню спавна для GTA IV / EFLC на ScriptHookDotNet.

## Установка
1. Поставь [ASI Loader](https://www.gtagarage.com/mods/show.php?id=7782) и **ScriptHookDotNet** (для патча 1.0.7.0 / 1.0.8.0 или через FusionFix).
2. Скопируй `SpawnMenu.cs` в `GTAIV\scripts\`.
3. Запусти игру, нажми **F7**.

## Управление
- **F7** — открыть/закрыть меню
- **↑ / ↓** — выбор
- **Enter** — заспавнить

## Что есть
| Пункт | Что делает |
|---|---|
| Волосатый мотороллер Короля Британии | Faggio в красно-синей окраске прямо перед игроком |

## Как добавить новую вещь
В конструкторе `SpawnMenu` допиши строку:
```csharp
Items.Add(new SpawnItem("Название", m => m.МойМетод()));
```
и метод, который спавнит нужное (`World.CreateVehicle`, `World.CreatePed`, `Player.Character.Weapons...`).

## Настоящая «волосатость»
Скриптом нельзя добавить новую 3D-модель — сейчас это перекрашенный Faggio.
Чтобы мотороллер правда был волосатым, нужна своя модель/текстура (`faggio.wft` / `.wtd`),
которую заменяют через OpenIV в `vehicles.img`. Если найдёшь или сделаешь меховую текстуру — подключим.
